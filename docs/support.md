# Vigil support

> Last reviewed: 2026-08-09
>
> Review again: whenever support, diagnostics, privacy, or account setup changes

Vigil has no separate Vigil account or developer-operated backend. Most setup
and refresh problems involve the selected provider, its credential, its current
response contract, or iOS scheduling.

## Before reporting a problem

1. Read the [setup guide](user-guide/setup.md) and
   [troubleshooting guide](user-guide/troubleshooting.md).
2. Confirm the credential type matches the selected provider. Global and China
   platform credentials are not interchangeable.
3. Pull to refresh and keep the exact status message Vigil displays.
4. In **Settings**, choose **Export diagnostic report** if support needs a
   bounded, credential-free report.

## Ask for help or report a bug

Use the [Vigil issue forms](https://github.com/ogprotege/vigil/issues/new/choose)
for product support and provider-change reports. Include the app version,
device/iOS version, provider name, and the status message. Never post API keys,
OAuth tokens, session cookies, authorization headers, raw provider responses,
or screenshots containing real account or billing details.

For privacy details, read the [Vigil Privacy Policy](privacy.md). For a suspected
security vulnerability, follow [SECURITY.md](../SECURITY.md) so sensitive details
are not exposed in a public issue.
