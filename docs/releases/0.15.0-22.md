## Release scope

Build 22 adds experimental **Grok Build** monitoring so Vigil can track Grok CLI / Grok Build credit usage on the phone.

**Grok Build is not the xAI API prepaid-balance integration.** The existing **xAI API** (`xai`) path still uses a Management Key plus team ID for prepaid balance. Grok Build (`grok`) uses xAI OIDC **device authorization** — the same family of short-code + browser approval flow as desktop `grok login` / `/login` — and polls the Grok Build CLI chat-proxy billing endpoint for monthly credit used/limit (with a percentage-only fallback and optional on-demand metrics).

Setup is a first-class **Connect Grok Build** route. Vigil mints its own renewable session in the iPhone Keychain; it never reads `~/.grok/auth.json`. The integration is labeled Experimental because the billing endpoint is undocumented, even with live-sanitized fixtures.
