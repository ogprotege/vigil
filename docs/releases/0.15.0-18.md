## Release scope

Build 18 fixes two TestFlight crash reports on build 17, both RUNNINGBOARD
`0xdead10cc`: iOS terminated the app because it was suspended while still
holding the history store's cross-process file lock or SQLite WAL locks. One
report caught the WAL checkpoint blocked in `fcntl` during connection close
after thirty minutes of uptime; the other caught a background launch opening
the WAL shared-memory file 3.2 seconds in.

Every lock-holding history read or write in the app process — the history IO
coordinator, the persistence tail of each fetch, and the direct append,
backfill, and delete calls — now runs inside a `SuspensionGuard`
background-task assertion so suspension waits until the locks are released.
VigilKit, the shared fetch service, and the widget extension are unchanged.
