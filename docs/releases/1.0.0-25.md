## Release scope

Build 25 changes only the Grok Build usage contract and its supporting tests,
fixtures, and documentation:

- Requests the same `format=credits` billing representation used by the
  current Grok CLI.
- Maps the provider's shared weekly `creditUsagePercent` and
  `currentPeriod.end` reset without inventing exact used or limit values.
- Retains compatibility for older responses that contain a positive monthly
  used/limit pair.
- Rejects the retired bare-endpoint response where a zero monthly limit is
  returned alongside nonzero usage, which caused build 24 to show **Provider
  changed**.

No intentional Settings, account-storage, privacy, widget, or notification
behavior changes relative to build 24.
