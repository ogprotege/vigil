## Release scope

Build 26 adds first-class OpenRouter authorization and hardens request,
storage, and lock boundaries. It does not change Vigil's product contract:
there is still no Vigil account, in-app purchase, user-generated content, or
developer backend.

- Guided OpenRouter setup mints a non-refreshing API key from OpenRouter's
  official authorization page. Pasting an existing key remains available.
- MiniMax Token Plan requests use the current vendor hosts.
- Grok device pages are pinned to xAI. Mismatched account/credential pairs
  never leave the device. Provider and Admin-history transports refuse
  redirects and stop at a 1 MiB body.
- Pending-notification queues, trusted-container reads, Release launch hooks,
  the device-owner lock, and hidden-widget labels fail closed.
