before commit `c4b55c2`. Xcode archives do not record the Git commit by default.
The existing path therefore cannot prove it contains the current candidate and
must not be uploaded.

Do not overwrite it. The replacement archive must use the commit-qualified new
path defined by the runbook:


Archive verification will cover the signed `.xcarchive`. It will not prove
App Store Connect processing, the delivered TestFlight package, Internal group
assignment, or physical-device behavior. Those remain separate gates.

## Release scope

The candidate reconstructs Vigil around one product question: which AI limit
needs attention next.

Included work:

- urgency-ranked Home summaries with provider names and real reset times;
- full provider windows, balances, provider-declared special lanes, and diagnostics in account
  detail;
- phone-native Claude and ChatGPT/Codex setup plus an Other Provider catalog;
- protected on-device SQLite history with observed and provider-imported
  provenance kept separate;
- optional official OpenAI API-organization completion-usage and cost imports;
- credential-free bounded diagnostics;
- fail-closed provider mapping and reset-safe account lifecycle handling;
- app-lock privacy cover, cacheless provider sessions, and legacy app-scoped
  network-storage cleanup;
- app and widget archive validation for signing, entitlements, privacy
  manifests, profiles, versions, and dSYMs.

Subscription names remain context, not invented denominators. Claude and
ChatGPT/Codex token or message ceilings appear only when the provider returns
an exact value. OpenAI API-organization imports are not ChatGPT or Codex
subscription history.
