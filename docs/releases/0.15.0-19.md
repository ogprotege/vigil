## Release scope

Build 19 makes provider refresh responsive again. Pull-to-refresh now fetches
on demand through a `bypassingPollFloor` path that skips the shared
min-interval floor while still honoring an active cross-process lease and any
unexpired 429 backoff. The automatic provider floor drops from 300 to 60
seconds in the registry and `protocol/providers.json`. The widget attempts a
fetch once its snapshot is five minutes old with a five-minute timeline
cadence (was thirty), and the background refresh task asks iOS for a run
fifteen minutes out (was thirty). iOS still decides when background work runs.

The fix landed through [PR #35](https://github.com/ogprotege/vigil/pull/35).
This build also carries the post-build-18 documentation and identity entries
listed in the changelog.
