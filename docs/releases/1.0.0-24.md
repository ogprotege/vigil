## Release scope

Build 24 is a reliability fix over the build 23 public candidate:

- Closes the TestFlight `RUNNINGBOARD 0xdead10cc` kill observed on 1.0.0 (23): overnight history reload held the account-lifecycle App Group flock (`captureActiveGeneration` → `FileManager.fileExists`) while iOS suspended the process.
- Structural choke point: every `AccountLifecycleStore` exclusive lock begins under `SuspensionGuard` before `flock` when compiled with `VIGIL_APP_HOST`.
- Guard-ordering fixes for history append/backfill, account retirement deletes, pending-event loads, and post-link snapshot reads.
- Widget omits `VIGIL_APP_HOST` / `SuspensionGuard` (accepted residual).

No intentional product or Settings behavior change relative to build 23.
