## Release scope

Build 17 fixes the ChatGPT / Codex account-linking transaction. OpenAI device
authorization already completed, but Vigil classified the provider's current
HTTP 200 usage body as schema drift and aborted before saving the credential or
account index.

The provider contract now accepts independently optional primary and secondary
windows and an inactive spend-control wrapper with a Boolean `reached: false`.
It still fails closed for active, concrete, unknown, or malformed controls. A
live-sanitized fixture records the observed shape without credentials or raw
account data.
