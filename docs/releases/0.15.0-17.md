## Release scope

Build 17 fixes the ChatGPT / Codex account-linking transaction. OpenAI device
authorization completed, but Vigil classified the provider's current HTTP 200
usage body as schema drift and aborted before saving the credential or account
index.

The provider contract now accepts independently optional primary and secondary
windows and an inactive spend-control wrapper with a Boolean `reached: false`.
It still fails closed for active, concrete, unknown, or malformed controls. A
live-sanitized fixture records the observed shape without credentials or raw
account data.

Artifact candidate `94320f4` also restores Vigil's public documentation identity
with the existing gauge mark, current screenshots, structured product guidance,
and a redesigned documentation index. It narrows history and diagnostic claims,
corrects the build 16 TestFlight label, and preserves the retired screenshots as
historical diagnosis evidence.

The README is user-facing release material. Under the release runbook, commit
`94320f4` invalidated the earlier artifact binding to `f68157e` even though it
did not change app source. No archive based on `f68157e` may be used for build
17. `94320f4134c20b328f0a5c6ad76c6a1fd99ef54e` is the only current artifact
candidate.
