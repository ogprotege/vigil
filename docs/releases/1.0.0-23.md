## Release scope

Build 23 is the first public App Store candidate. It carries forward all 15
provider integrations from build 22, including experimental Grok Build, and
adds a deliberately small Settings surface:

- System, Light, and Dark appearance, with the original dark palette retained;
- system-owned navigation and toolbar chrome that adopts native Liquid Glass;
- fixed 80% and 95% usage alerts with an off switch and optional generic copy;
- optional hidden percentages, limits, spend, and balances in widgets;
- a pause for automatic app, background, and widget checks while manual refresh remains available;
- accurate provider-floor copy, local privacy guidance, version, and support access.
